## Stack

Static HTML site. No build step.

- `styles.css` — global styles, light/dark tokens
- `project-page.css` — case-study layout
- `site.js` — shared UI
- `theme.js` — light / dark theme toggle
- `assets/` — fonts (Ametea) and other static files
- `images/` — hero, project banners, gallery
- `public/` — resume PDF and public downloads
- `_headers` — Netlify headers

Hosted on [Netlify](https://www.netlify.com/). Pretty URLs map `.html` files to paths such as `/about` and `/project-urban-watcher`.

## Local preview

```bash
git clone https://github.com/kimichan-git/kimichan-studio.git

```

Open `index.html` in a browser, or serve the folder:

