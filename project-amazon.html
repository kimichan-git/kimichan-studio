Amazon Listing Graphics

Overview

Amazon is a major online retail platform. For this project I designed promotional materials and listing assets that help products stand out in a crowded marketplace — from main images to A+ content style layouts and promotional banners.

Role & deliverables

  • Product listing main images and secondary images
  • Promotional banners and sales graphics
  • Visual hierarchy and typography for clarity at small sizes
  • Consistent brand treatment across the set

Approach

E-commerce graphics need to work at thumbnail size and still communicate value. I focused on clean composition, accurate product representation, and a clear value message so shoppers can understand the offer quickly.
