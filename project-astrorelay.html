AstroRelay Client UI

Overview

AstroRelay Client (Windows) provides remote work and device access with minimal steps. The goal was a clear, low-friction interface so users can connect and work without wrestling with complexity.

Role & deliverables

  • UX flows for connection and device access
  • High-fidelity UI for the Windows client
  • Clear status and feedback states
  • Consistent visual language with the admin console

Approach

I prioritised clarity over decoration: straightforward hierarchy, readable typography, and obvious primary actions. The interface supports both first-time setup and everyday use so users stay confident at every step.
